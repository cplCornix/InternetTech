## Стек технологий

- Python 3.11+
- PostgreSQL 15
- psycopg2-binary
- Docker / docker-compose

## Локальное развертывание

### Предварительные требования

- Установленный Python 3.11 или выше
- Установленный PostgreSQL (или доступ к удалённому серверу)
- Git

### Шаги

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   
2. Запустите скрипт автоматической настройки:

   **Linux/macOS:**
   ```bash
   chmod +x scripts/setup.sh
   ./scripts/setup.sh
   ```
   
    **Windows:**
   ```bash
   scripts\setup.bat
   ```

    Скрипт создаст виртуальное окружение, установит зависимости и скопирует .env.example в .env.

3. Отредактируйте файл .env, указав параметры подключения к вашей PostgreSQL (если необходимо).
 
4. Убедитесь, что PostgreSQL запущен и база данных employee_db существует (можно создать заранее или скрипт создаст таблицы, но не базу).

5. Запустите приложение:
   ```bash
   python -m app.main
   ```
   
   Приложение создаст таблицу employee, загрузит тестовые данные (если таблица пуста) и выведет результаты двух запросов.

## Развертывание через Docker

### Требования
- Установленные Docker и docker-compose

### Запуск:

1. Клонируйте репозиторий и перейдите в папку проекта.

2. Выполните команду:
   ```bash
   docker-compose up
   ```
   Docker поднимет контейнер с PostgreSQL и контейнер с приложением. Приложение запустится один раз и выведет результаты в консоль. Для повторного запуска используйте docker-compose run app
